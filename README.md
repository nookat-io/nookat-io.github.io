# nookat.io

The website for [Nookat](https://github.com/nookat-io/nookat), a small, native, open-source desktop app for Docker-compatible containers, images, volumes and networks.

Live at [nookat.io](https://nookat.io).

## What's on the page

- An interactive preview of the app with sample data, built from the real app's screens and actions.
- A download button for the visitor's OS and CPU, built from the latest GitHub release, with every other installer and its size listed below.
- Live project numbers (stars, forks, contributors, installer downloads) from the GitHub API, hidden rather than guessed when the API is unavailable.

## Development

Requires Node.js 22.12 or later.

```bash
npm install
npm run dev            # start the dev server
npm run check          # typecheck, lint and formatting check
npm run build:single   # production build: one self-contained dist/index.html plus public/ assets
npm run preview        # serve the last build
```

Install the pre-commit hooks with `just install` (or `pip install pre-commit && pre-commit install`).

## Stack

React 19, TypeScript, Tailwind CSS v4 and Vite, with `vite-plugin-singlefile` for the deployed build.
Fonts are Geist and Geist Mono, vendored under the SIL Open Font License.

## Brand assets

The logo kit, favicons, app icon and Open Graph image are generated by `scripts/brand/` (requires Google Chrome):

```bash
cd scripts/brand
npm install
npm run all
```

The logo files are also linked from the site footer, in `public/brand/`.

## Deployment

Publishing a release in this repository (or running the workflow manually) builds the site and deploys it to GitHub Pages.
